PacketSim - All-in-One Network Simulator
=========================================

PacketSim is a modern, high-fidelity interactive network simulator designed for learning and testing topologies.

How to Run:
-----------
1. OPTION A (Quick Start):
   Simply double-click the "index.html" file to open it in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari).

2. OPTION B (Local HTTP Server - Recommended for loading custom topology files):
   To avoid browser security limitations when loading or saving local JSON topology profiles, run a simple local web server:
   
   - Using Python (if installed):
     Open a command prompt/terminal in this folder and run:
     python -m http.server 8000
     Then open http://localhost:8000 in your browser.

   - Using Node.js / npm:
     Install and run 'serve':
     npx serve
     Then open the address provided in your terminal (usually http://localhost:3000).

Features:
---------
- Interactive Canvas: Drag and drop network elements (PC, Switch, Router, Server).
- Drag & Drop Zoom & Pan: Scroll to zoom and use the "Pan Canvas" tool to navigate.
- Dijkstra Routing Engine: Recalculates paths automatically based on Hops, Latency, or Loss metrics.
- Hybrid Hardware Adapters: Includes a virtual terminal command line simulating configurations for open systems (Linux Containers, OpenWrt, MikroTik ROS).
- Performance Telemetry: In-app Recharts telemetry showing latency logs and optimal routes.
- Themes: Custom selector to toggle between Dark Slate, Modern Light, Cyberpunk Neon, and Emerald Forest themes.
- Save & Load: Export your network topologies as JSON files and load them back later.
